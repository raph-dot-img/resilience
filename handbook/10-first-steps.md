# First steps

Welcome to Resilience OS: a computer system designed to keep working when
the Internet does not.

EVERYTHING HERE WORKS OFFLINE
  The guides, tools and games on this computer are stored locally. Nothing
  in the main menu needs an Internet connection unless its description says
  so.

MOVING AROUND
  Up / Down       move the highlight
  Enter           open the highlighted item
  Esc             go back
  1 - 9           open a numbered item directly
  /               search for anything
  F1              help for the current screen
  F5              detailed system status

KEYBOARD LAYOUT
  The keyboard starts in the system's layout (US unless the system was
  built otherwise). To use another one, search for "keyboard" or open
  SYSTEM MANAGEMENT > Settings and choose a "Keyboard" line. Your choice
  is loaded again each time you log in. Login prompts always use the
  system's layout, so type passwords there with that layout.

READING THE STATUS PANEL
  Each line starts with a marker so you never depend on colour alone:
    [OK]  working normally
    [!!]  needs your attention (for example a low battery)
    [--]  information only

USING PROGRAMS
  When you open a program, the interface steps aside and waits. Quit the
  program normally (its description tells you how) and you come back here.

LEAVING
  Press q on the main menu, or use SYSTEM MANAGEMENT > Log out, Restart
  computer or Power off. Each asks for confirmation; the safe answer
  (Cancel) is always selected first.
