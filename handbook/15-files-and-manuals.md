# Files and manuals

FINDING A FILE
  PRODUCTIVITY > Find & view files. Type part of the file's name: the list
  shows every file in your home folder and on open USB sticks whose name
  matches. Several words must all match. Hidden files are not searched.
  F2 searches again, for example after opening a stick.

READING IT
  Press Enter on a file:
    text files              shown as text
    PDF documents           their text (a scanned PDF has none)
    .csv and .tsv tables    shown as a table: arrows move between rows
                            and columns
    archives (.zip, .tar)   the list of what is inside; nothing is unpacked
    resource packs (.zim)   opened in the offline library
  Esc goes back. Nothing is ever changed, unpacked or run from a file.

CHECKING A FILE
  F3 shows a file's size, date and SHA-256 fingerprint. When someone
  publishes the fingerprint of a file (a download, a document sent to you),
  compare the two: if they are equal, the file is exactly the one they
  published.

MANUAL PAGES
  KNOWLEDGE & DOCUMENTATION > Manual pages (man). Type the name of a
  command, for example ls, and press Enter. Some names exist in several
  sections; type the section first, for example 5 passwd for the file
  rather than the command.
  Type a few words instead (copy files, network) to search the manuals.
  In a page: Space next page, b previous, / searches, q quits.
