# When something goes wrong

YOUR FILES ARE SEPARATE FROM THE SYSTEM
  Your documents live in your home folder. Rolling the system back never
  touches them, and restoring files never changes the system.
  To keep a copy of your files elsewhere, see "Backups and USB sticks".

START HERE: SYSTEM MANAGEMENT > Recovery & diagnostics
  System health      what is running, what failed, recent error messages
  Generations        every earlier version of the system, how to start one,
                     and how to keep starting an earlier one
  Diagnostic report  saves a text file in your Diagnostics folder to show
                     someone who can help (no passwords, no addresses)
  Only "make default" in Generations changes the system, and only after an
  administrator types their password. Nothing there changes your files.

IF THE INTERFACE STOPS
  It restarts by itself after you press Enter. The message on screen shows
  where the error log is. If it keeps failing, press Alt+F2 for another
  console where you can log in.

IF THE SYSTEM WILL NOT START OR BEHAVES BADLY AFTER A CHANGE
  Restart the computer. In the boot menu, choose an earlier entry (an older
  "generation") and press Enter. Resilience keeps previous versions of the
  whole system so you can always go back to one that worked. Only this
  start uses the older version; the next restart returns to the newest one.

TO KEEP STARTING AN EARLIER VERSION
  Recovery & diagnostics > System generations, choose the generation and
  press Enter. After you confirm, an administrator types their password.
  The computer keeps running as it is; the chosen generation starts from
  the next restart on, every time. Newer generations stay in the boot menu,
  and you can make one of them the default again the same way.
  An older generation also has older system software, including problems
  that were fixed later: go back to the newest one once it works again.

IF NOTHING ELSE WORKS
  Start the computer from the Resilience USB stick (the live system). Your
  installed system and your files are not changed by doing this. The live
  system has its own Recovery section and handbook.

  There is no "root" password on Resilience: repairs are made by an
  administrator (an Advanced account), from another console (Ctrl-Alt-F2)
  or from the live system.

IF A PROGRAM IS MARKED [UNAVAILABLE]
  Its files are missing from this system. The rest of the system is not
  affected. SYSTEM MANAGEMENT > System status lists every unavailable
  program; show that screen to your administrator.

MEDICAL, SAFETY OR EMERGENCY SITUATIONS
  Offline documents are no substitute for qualified help. Contact emergency
  services whenever you can.
