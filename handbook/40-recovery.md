# When something goes wrong

YOUR FILES ARE SEPARATE FROM THE SYSTEM
  Your documents live in your home folder. Rolling the system back never
  touches them, and restoring files never changes the system.

IF THE INTERFACE STOPS
  It restarts by itself after you press Enter. The message on screen shows
  where the error log is. If it keeps failing, press Alt+F2 for another
  console where you can log in.

IF THE SYSTEM WILL NOT START OR BEHAVES BADLY AFTER A CHANGE
  Restart the computer. In the boot menu, choose an earlier entry (an older
  "generation"). Resilience keeps previous versions of the whole system so
  you can always go back to one that worked.

IF A PROGRAM IS MARKED [UNAVAILABLE]
  Its files are missing from this system. The rest of the system is not
  affected. SYSTEM MANAGEMENT > System status lists every unavailable
  program; show that screen to your administrator.

MEDICAL, SAFETY OR EMERGENCY SITUATIONS
  Offline documents are no substitute for qualified help. Contact emergency
  services whenever you can.
